Visual direction

A Swiss/editorial structural backbone carrying a Neo-Memphis expressive palette — precise where it counts, playful on purpose.

Aesthetic

Swiss structure (grid, numbered sections, typographic hierarchy) + Neo-Memphis expression (categorical palette as meaning, shape accents) + Editorial voice (oversized display, 400↔800 weight).

Color — Level 3, Full Palette

Primary an electric violet-blue (H267°), not a generic SaaS blue. Neutrals share one violet temperature; bright fills carry dark ink text (signature).

Type

Bricolage Grotesque (display/headings), Geist (body), Nunito (micro-labels). Weight 400→800, 11.5px→100px.

Shape

Friendly-to-rounded, tiered: chips 8 · buttons/inputs 12 · cards 18 · modals 22 · pills full. Never uniform.

Not

Not generic SaaS (no #FAFAFA grays, no 220–240° blue, no uniform radius, no pure-black shadow). Not bubbly-pill or soft-UI.

Type

Ten roles on a Major-Third (1.25) base-16 scale. Each differentiated by family, weight, line-height, and tracking — not size alone.

Radius & elevation

Radius is tiered by component weight. Shadows are two-layer, violet-tinted ink — never pure black.

Spacing

4px base, mixed-density scale: fine stops for component internals, generous stops for layout. Three semantic aliases.

Buttons

Interactive tier (radius 12px), 44px min target, consistent focus ring.

Primary — the single most important action on a view (Start an intake). One per section.
Secondary — a strong alternate action; dark ink on the pink fill.
Outline / Ghost — lower-emphasis actions (Cancel, tertiary links) that shouldn't compete with primary.

Badges

Small status/label tags (radius 8px), dark-on-bright.

NeutralDeliveredIn progressBlockedIn review
Semantic (success/warning/error) — object status only. Don't use a categorical accent to imply status.
Categorical (blue/pink/mint/…) — sectioning, taxonomy, and data series where the hue carries meaning, not status.

Forms

Inputs share .field. Labels use the uppercase label role. Errors set aria-invalid.

Labels, not placeholders — every field has a visible <label>; placeholders show format only.
Errors — set the field to .is-error + aria-invalid="true" and pair with a .field-error message.

Cards & overlays

Container tier (radius 18px). Interactive cards lift on hover; the night card is the inverted/flagship treatment. Overlays use native <dialog> / [popover].
